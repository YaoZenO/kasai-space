# 城市区域归属字段台账（region / belt / zone / bohai）

## 为什么要有这套字段

站内有一批区域榜（华东、华南、西北十大旅游城市、环渤海十三市…），
computed 榜靠 `filter` 限定候选范围，而 filter 只能按字段匹配——城市必须先有区域字段。
区域归属看似是常识，但**不能靠人一条条手写**：晋江那次就是「没有规则、全凭手写顺序」翻的车。
所以映射表写死在 `tools/tag-city-regions.js`，默认 dry-run 打印统计，核对后才 `--write`。

## 三套划分 + 一个经济圈

| 字段 | 划分 | 依据 |
|---|---|---|
| `region` | 七大区（华北 / 东北 / 华东 / 华中 / 华南 / 西南 / 西北 / 台湾） | 地理大区通行划分 |
| `belt` | 三大地带（东部 / 中部 / 西部） | 国家统计局三大地带口径；港澳台不在该划分内，不标 |
| `zone` | 南北（北方 / 南方） | 秦岭—淮河线；跨界的省按城市名例外 |
| `bohai` | 环渤海 | 沿岸城市 + 北京、天津（窄口径） |

### region（省级 → 大区）

华北：北京、天津、河北、山西、内蒙古｜东北：辽宁、吉林、黑龙江｜
华东：上海、江苏、浙江、安徽、福建、江西、山东、中国台湾地区（单列「台湾」）｜
华中：河南、湖北、湖南｜华南：广东、广西、海南、中国香港、中国澳门｜
西南：重庆、四川、贵州、云南、西藏｜西北：陕西、甘肃、青海、宁夏、新疆

### belt（国家统计局三大地带）

东部：北京、天津、河北、辽宁、上海、江苏、浙江、福建、山东、广东、广西、海南
中部：山西、内蒙古、吉林、黑龙江、安徽、江西、河南、湖北、湖南
西部：重庆、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆

### zone（秦岭—淮河线，跨界的省按城市例外）

- 主体算北方：北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、山东、
  **河南、陕西、甘肃**、青海、宁夏、新疆
  - 其中的南方城市例外：河南（信阳、南阳、驻马店）｜陕西（汉中、安康、商洛）｜甘肃（陇南）
- 主体算南方：上海、**江苏、安徽**、浙江、福建、江西、湖北、湖南、广东、广西、海南、
  重庆、四川、贵州、云南、西藏、中国香港、中国澳门、中国台湾地区
  - 其中的北方城市例外：江苏（徐州、连云港、宿迁）｜安徽（淮北、亳州、宿州、蚌埠、阜阳、淮南）

> 南北划分存在学术争议（河南、江苏、安徽、陕西、甘肃均跨线）。这里按**省级主体归属 +
> 明确跨界城市例外**处理，并在对应榜单的页面上写明判据，读者可自行判断是否认同。

### bohai（环渤海，窄口径）

北京、天津 + 河北（秦皇岛、唐山、沧州）+ 辽宁（大连、丹东、营口、盘锦、锦州、葫芦岛）+
山东（青岛、烟台、威海、潍坊、东营、滨州、日照）= 18 座。
**不含**内陆的沈阳、济南、石家庄等「环渤海经济圈」广义成员——范围口径不同名次就不同，
页面 note 里写明了这一取舍。

## 落库结果

- `region` 338 条、`belt` 335 条、`zone` 338 条、`bohai` 18 条。
- 未标注 93 条：库里省份缺失的条目（县级、国外城市、「XX十大 / 之乡」装饰名空壳等）。
  其中真实地级市缺省份的（三亚、吉林、白山、延边）已先补省份再标注；
  其余空壳条目留给后续清理任务处理（E-076 同族），不进区域榜候选池。

## 与 5A 数据的关系

区域旅游榜用的是 `scenic_5a`（国家 5A 级旅游景区数量）。为了让区域榜的候选池完整，
库内 431 座城市**全部**有 `scenic_5a`：名单里出现的按实际家数，未出现的按 **0 家**——
依据是文旅部名单为全国全量名单（数据截止 2025-03-11，359 条），未出现即 0，这是可核对的事实，
不是占位值也不是估算。补 0 共 220 座城市，批次文件 `scenic-5a-2025-zero.json`。

副作用：池内最小值变成 0，对数刻度不再适用（ln 要求恒正），
「中国十大旅游城市」的 `scenic_5a` 刻度随之由对数改为线性；前十不变。
