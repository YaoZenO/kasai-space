这是一篇学习资料整理，按「入门 → 打基础 → 精进 → 实战 → 进阶」五个阶段，汇总了 C++ 求职方向上口碑较好的书籍与视频，并标注了必看 / 选看。建议按自己的基础选择起点，不必全跟。资源链接汇总在文末。

## 第一阶段：入门

入门阶段不建议直接啃黑皮书。经典教材很好，但零基础时读容易劝退，先把语言骨架搭起来更重要。

### 1. 郝斌老师的 C 语言教程（选看）

地址：https://www.bilibili.com/video/BV1os411h77o

如果你已经有 Java、Python 等语言基础，这一阶段可以直接跳过；如果完全零基础，建议过一遍。指针、内存这些概念不清楚的话，后面学智能指针会很吃力。

### 2. 黑马培训班的 C++ 教程（必看）

地址：https://www.bilibili.com/video/BV1Tb411j7uM

必看。最好跟着视频一起敲——开始慢、看不懂都正常，跟着敲就是了。

## 第二阶段：打基础

这是整个路线里最重要的阶段，目标是语言基础扎实，后期学什么都快。分书籍和视频两条线。

### 1. 《C++ Primer 第五版》或《C++ Primer Plus 第六版》

这是两本定位完全不同的书：

- **《C++ Primer 第五版》**：适合有基础的选手。最好有 C 语言基础，也就是能跳过郝斌教程、直接看黑马教程的那批人；有其他语言基础更好。
- **《C++ Primer Plus 第六版》**：零基础向，讲得细甚至有点啰嗦。适合没有任何语言基础的人，建议看完入门阶段的视频再买它，不要和第五版混买。

两本书的共同提醒：**课后练习不要跳过**。不必每题都细做，但每小节后的前 2-3 题一定要自己写一遍——看懂和会写是两回事。

《C++ Primer 第五版》前 8 章是基础，需要认真看；第 9-12 章讲容器和算法；第 13-19 章是拷贝、重载等进阶内容，第一遍理解不了没关系，后期遇到问题再回来翻对应的章节。

### 2. 粗看侯捷老师的三个视频

看书枯燥，这个阶段建议穿插视频：提前粗看第三阶段的三个必看视频——侯捷老师的 **STL 泛型编程、C++11 新特性、内存管理与分析**。

前提是至少学完 C++ 基础（比如《C++ Primer 第五版》的前八章）。看不懂的名词有个印象就行，不求理解透彻——这三个视频本身就值得反复看，第三阶段还会再细看一遍。

## 第三阶段：精进

### 1. 必看的两本书 + 一章，选看的两本书

必看：

- **《STL 源码剖析》**——走进 C++ 最常用库的底层，配合侯捷的 STL 视频效果更好；
- **《Effective C++》**——写给自以为「精通」C++ 的人，管孔窥豹一下语言的奥秘；
- **《深度探索 C++ 对象模型》第三章（虚函数）**——面试高频，也是区分基本功的分水岭。

选看（优先级后放，找到工作再说）：

- 《More Effective C++》
- 《深度探索 C++ 对象模型》第三章以外的部分

为什么必看这三样？往近了说，正规的 C++ 面试基本都会问 STL，还可能根据回答决定要不要深挖（比如 Vector 扩容机制、map 与 unordered_map 的底层结构、哈希冲突怎么解决）；往远了说，这些底层的认知会直接反映在写代码和刷题的效率上。

### 2. 必看的三个视频和一个选看视频

侯捷老师是台湾的 C++ 开发者，学 C++ 的人大多看过他的课程。

必看（重要性递减）：

1. **STL 泛型编程**——配合《STL 源码剖析》理解容器底层；
2. **C++11 新特性**——配合《C++ Primer 第五版》里的对应章节；
3. **内存管理与分析**。

选看：《程序的生前死后》。

纯靠自己看书容易钻牛角尖，有人带着讲会顺畅很多。

## 第四阶段：实战

认真学完前三阶段，语言层面基本够用了。再补数据结构与算法、操作系统、计算机网络、数据库，就可以开始找工作了。

如果想在 C++ 方向走下去，网络编程是绕不开的一环——学 C++ 不像学 Java 那样能不断做出可见的小项目，很长一段时间陪伴你的只有命令行，而网络编程是少数能快速获得正反馈的阶段。建议自己动手写一个服务器。

### 1. 两本必看的书、一本选看的书

必看：

- **《TCP/IP 网络编程》**——手把手带写网络通信的例子，每章一个案例；不足是原理讲得浅，很多内容一笔带过。
- **《Linux 高性能服务端编程》（游双）**——告诉你「为什么」，服务端开发的案头书。

选看：

- **《Mudo：Linux 多线程服务端编程》（陈硕）**——好书但门槛高，工业界用 Mudo 的不多，不专门做服务端可以先不看。

### 2. 一个选看的视频

陈硕老师有一个和《Mudo》配套的视频，门槛同样较高，不专门从事服务端开发的话可以跳过。

### 3. 一个付费专栏（可选）

牛客网的 Linux C/C++ 服务器开发专栏（付费）：

https://www.nowcoder.com/courses/cover/live/504?coupon=AcNi2gn

内容基本覆盖上面两本书的主要知识点，适合习惯跟着视频学的人。但免费资源里也有精品，优先选经典、公认好的；能啃得动书的话，还是更推荐《TCP/IP 网络编程》+《Linux 高性能服务端编程》。

## 第五阶段：大成

这一阶段的书籍更多用在工作实战中，求职阶段基本不需要：

- 《C++ 沉思录》
- 《C++ 模板元编程》
- 《C++ 并发编程实战》

拿到 offer、确定走 C++ 方向之后再看不迟。另外建议把《C++ Primer 第五版》回归字典属性，放在工位上，遇到不确定的当场翻。

## 结语

语言原理是相通的。C++ 的基本功打牢，将来即使转 Java/Go，学习成本也会比别人小得多。种一棵树的最好时间是十年前，其次是现在。
