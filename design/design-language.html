01 / Principles

设计立场

五条立场决定所有后续取舍。与新需求冲突时，以立场为准。

01

纸面优先

整站只有一张"纸"。暖纸白是唯一底色，不铺灰底、不卡中卡；层级靠留白与发丝线，不靠阴影堆叠。

DO 页面即纸面 / DON'T 卡片套卡片

02

排版即结构

字号、字重、字距与留白承担全部视觉层级。标题 900 字重 + 紧字距，正文 17px/1.75，上限 38em。

DO 用字重分层 / DON'T 用边框围层级

03

克制强调

锈红是全站唯一交互强调色（链接、当前态、焦点）。块色只许开"门"——做内容入口，不做装饰。

DO 锈红点睛 / DON'T 块色铺满整页

04

非对称构图

左身份域、右内容墙；错位瓷砖、宽窄栏交替。拒绝居中对称的模板构图。继承首页 V2 既有骨架。

DO 错位与不对称 / DON'T 居中英雄区模板

05

真实数据驱动

铁律：无数据不渲染模块；计数 = 真实条目数；Since 年份由最早文章推导；不造文案、不用空卡片。

DO 空则不渲染 / DON'T 占位假数据

03 / Typography

字体

三轨制：展示轨撑门面，正文轨管阅读，档案轨（等宽）给日期、标记与计数——等宽轨是"档案"身份的来源，沿用现状。

Display · 展示轨

"Archivo", "Arial Black", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif

拉丁品牌字与大数字；900 字重，大写 + 字距 −0.04~−0.06em。中文不进此轨的紧字距，走黑体 Heavy。

Sans · 正文轨

system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif

全部中文正文与 UI 文字。正文 17px/1.75，辅助 13–14px。中文标题不使用负字距。

Mono · 档案轨

"Cascadia Code", "JetBrains Mono", Consolas, "SF Mono", Menlo, monospace

日期、FEATURED / SINCE / TOP 标记、计数、标签。全大写只用于拉丁字母。

04 / Space & Shape

空间与形状

间距七阶、圆角四档、阴影只给浮层、分区全靠发丝线。

间距阶

  • 区块间距桌面 64px、移动 40px；组件内 8–16px；组件间 24px。

圆角

999 胶囊
22 瓷砖
12 小卡
8 控件

阴影与线

  • 全站唯一阴影：--site-float-shadow: 0 12px 32px -14px rgba(42,37,29,.28)，只给悬浮胶囊导航。
  • 内容卡片一律 1px 发丝线，不用阴影；表头、页脚上缘用强线 .24。
  • 瓷砖入口格可用 inset 1px 内描边（浅色 rgba(42,37,29,.10) / 深色 rgba(255,255,255,.14)）。

06 / Motion

动效

动效只做两件事：入场一次性、hover 即时反馈。常驻动画默认没有。

入场（一次性）

仅首页首访播放：header 落下 → 大标题逐行升起 → 内容墙淡入，2.1s 就位。

WAAPI · EXPO(0.16,1,0.3,1)
瓷砖循环（可选）

仅当内容墙有真实图片素材才启用；14.6s/循环、相邻列反向、移动端静帧。

CSS @keyframes · translate3d
hover

≤120ms，只动 transform/opacity。链接变锈红，行列表 2px 位移，瓷砖不缩放。

transition ≤ 120ms
降级与禁项

prefers-reduced-motion 下全部静态。禁：全页常驻 marquee、scale 画布、视差、自动轮播、骨架屏。

@media (prefers-reduced-motion)
07 / Texture

质感

纸感来自底色与排版，颗粒只叠在色块上——左为无颗粒，右为叠 13% multiply 颗粒；碳黑卡用 5% screen。

  • 颗粒纹理为内联 SVG feTurbulence data-URI，无外部请求；块色瓷砖 opacity .12–.14 multiply。
  • 正文纸面、导航、列表一律不加纹理；头像沿用主题猫插画，经 _config.yml 统一管理可替换，布局按方形裁切不依赖图片比例。

ATRIUM MTL 每一项手法的取舍决定与理由。

参考做法决定理由
Archivo 900 海报标题 + 紧字距取瑞士排版骨架成立；中文场景走黑体 Heavy，不硬套负字距
纸白底 + 近黑字 + 三强调色取色板本地化为既有锈红体系，强调色从 3 个收敛为 1 个
块色瓷砖做内容入口取映射现有 wall-cell 入口格；沿用"整页 ≤2 处"纪律
悬浮胶囊导航取即已上线的方案 C，品牌左 / 胶囊中 / 搜索右
纸面颗粒纹理取限定瓷砖与深色卡，正文纸面不叠加
首屏一次性入场编排取2.1s 时间轴收编进动效规范，reduced-motion 全降级
1280×800 固定画布 + scale舍文字随缩放微糊、用户缩放失效、维护按画布算坐标——改真响应式
全页 overflow:hidden 视口锁定舍真实移动端有裁切风险；内容必须可滚动可回流
常驻 marquee 无限循环舍降级为"有真实素材才可选启用"的局部组件
虚构电话 / 展览等布景内容舍真实数据铁律：无数据不渲染，不造文案
font-display: block舍博客以首屏为先，用 swap + 系统字体兜底
SVG 内联图标 / 线稿语言取零依赖、随主题变色，管理后台线稿图标同源
09 / Implementation

落地映射

本语言全部落进 site.css 分区与既有数据机制，不动架构。

SITE.CSS · 分区落点
tokens → 基础 → 组件 → 逐页
  • 1 tokens：补 --paper / --ink / --font-display / --radius-tile 等
  • 2 基础：纸面底色、selection（已有）、正文 measure
  • 3 组件：胶囊导航（已有）+ .tile 瓷砖 + FEATURED 卡 + 引用块
  • 4 逐页：index / archives / post 阅读排版
数据机制 · 不变
真实数据驱动
  • featured: true 指定代表作，缺省最新一篇
  • 模块扩展走 Hexo data files 注册表
  • Since 由最早文章日期推导
  • 无数据模块不渲染、计数必真
红线 · 不动
保护清单
  • inject_point、插件、统计与备案配置
  • 加密文章逻辑与永久链接规则
  • /admin 管理后台（棕红强调语汇保持现状）
  • 全文换行与全角标点原样保留
验收 · Checklist
每次改动后核对
  • 1280 / 375 两档无横向滚动
  • reduced-motion 全静态可用
  • 空数据页无空卡片、无假计数
  • 对比度：正文 AA，强调文本加粗
