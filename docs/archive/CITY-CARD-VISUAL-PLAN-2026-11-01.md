## 2. 图型判定

### 2.1 有搞头（本轮采纳）

**A. 指标分位分布条**（替代/增强现在的文字徽标）
- 每项指标画一条横轴：候选池内每个城市一个刻度，本城用 accent 圆点，中位加深刻度。
- **横轴用「位次百分位」不用数值轴**——GDP 池 52.28 到 56708.71，数值轴会把
  95% 的城市压成一条缝；位次轴是对「从高到低第几位」的直接可视化，与现行
  「位次是事实陈述、不含优劣评价」口径完全同构（cityrank-e2e S17 锁的就是这个口径）。
- 草样见会话内渲染（GDP / 进出口 / 7 月均温三条，数字全部现算）。

**B. 重点指标 Top-N 条形图**（每城 1–2 张）
- 取该城排位最好的 1–2 个规模类指标（如 GDP 前 6），横向条形图，本城 accent 高亮。
- 纯排序事实呈现，数据来自候选池现算，与榜单口径同一真相。

**C. 头图双分支**（图文结合的「图」，已落地，2026-11-01 上海试点）
- 图源：**网络授权图库**（Unsplash License——免费商用、可下载存本地、无需署名但站内
  保留出处），不用主人私人照片、不做外链热链。下载后存
  `source/img/cities/<slug>.jpg`，逐城找「页面明确标注城市」的照片，人工核验画面。
- 双闸登记制：`source/_data/cityphotos.yml` 登记署名 **且** 文件存在才渲染，
  缺任一不出图（无出处图与死链都不允许）；生成器（Node 侧有 fs）做检测，模板零判断。
- 无图城市不渲染任何占位。远期可选：数据纹样支（仿节日页 `.fs-figure--css` 先例）。
- 配一段 2–3 句的档案导语（只写数据可支撑的事实：排位、总量档位），
  不写风景抒情，避免无来源描述。

### 2.2 没搞头 / 暂不碰（本轮否掉）

- **折线图**：数据库没有逐年时序，画不了。要做需先逐年回填统计公报
  （数据工程，工作量与来源核验成本远大于本页改版）。列为远期，
  等某项指标（如 GDP 或常住人口）攒满 ≥5 年再做。
- **雷达图**：跨指标雷达需要归一化成综合分，等于在做综合评价，
  与「位次不含优劣评价」的口径红线冲突。
- **地图**：中国地图类可视化涉及审图合规（国界省界标准地图），
  收益配不上合规成本，不碰。
- **ECharts 等图表库**：运行时依赖 1MB+，与全站零 JS 依赖的静态架构不匹配。
  全部图表走**构建期 SVG**：helper 现算、产物可复算、无运行时脚本。

### 2.3 地图（主人 2026-11-01 拍板要做，列 P4）

合规边界（《地图管理条例》口径）：
1. **审图不是必然门槛**：直接使用自然资源部标准地图底图、且不改动地图内容
   （只按省份填色）的，可不再送审核；一旦自绘边界或改动国界省界，就必须送审——
   所以路线定为「权威边界源 + 零边界改动」。
2. **数据源白名单**：边界几何必须来自权威源——自然资源部标准地图服务、
   天地图 / 全国地理信息资源目录服务系统（webmap.cn 1:100 万公众版）；
   阿里 DataV GeoAtlas（官方同源数据、业界通用）可用但须核验完整性。
   Google/OSM 等海外源一律禁用。
3. **领土完整性红线**（本项目已有 E-067 前科）：台湾必须为省级色块、
   南海诸岛（十段线）必须呈现（主图或标准小图）、藏南 / 阿克赛钦不得缺角。
   任何一处缺失即下线。
4. 技术路线：边界 GeoJSON 入库存 `tools/`，构建期 d3-geo（或手写投影）出 SVG
   静态图，本城所在省 accent 高亮，其余省中性色；不引运行时地图 SDK
   （腾讯 / 高德 GL JS 是交互地图方案，静态页用不上，还引入 key 管理负担）。
5. 落地前先写边界完整性断言（省级面数、台湾在列、南海诸岛要素存在），
   仿 S19 锁法进 cityrank-e2e。

## 3. 技术路线

1. `themes/fluid/scripts/helpers/cityrank-data.js` 扩展：`cityMetricPool(field)`
   返回 {values, min, median, max}（现算，不落盘、不手抄）。
2. 新 helper `cr-chart.js`：纯函数生成 SVG 字符串（分布条 / 条形图），
   模板里 `<%- %>` 内联输出；数值文本与刻度位置全部由数据算出。
3. `city.ejs` 分支：厚档案城市（指标数 ≥ 阈值，暂定 10）渲染图文版式；
   薄档案城市维持现有列表。
4. 测试（cityrank-e2e 新增 S19）：
   - SVG 内标注值与 helper 独立复算逐项一致（对齐 S17 锁法）；
   - 图内不出现估算值（缺值字段不画图，只进 [待补] 列表）；
   - 无图分支不泄漏 `--cr-fig-` 规则（仿 E-064 产物断言思路）。
