## 1. 一句话概念

首页不是封面加列表，是一张贴在纸上的图纸配一把量自己档案的尺：尺上每一根条都是
一个月，条高就是这个月写了几条；拖到没有记录的那天，它也会老实说「这一天没有记录」。

空间隐喻：**测绘台**。三层——图纸（照片与身份）、仪表（刻度尺与读数）、档案（记录本体）。

## 2. 为什么是这把尺

现状（J2）把内容按时间倒序排成一列，时间是行首一个日期字符串。读者知道「最新一条
是 11-04」，不知道「这个站什么时候密集、什么时候停了两年」。

站点的真实分布是：2023-04 一条，之后空 31 个月，2026-04 起重新有东西，2026-10 一次
爆发 11 条。这个形状本身是内容，不该被一列行首日期抹平。

尺把这个形状画出来，并且让访问者能上手：拖到任何一个日子，读数条给出当天全部记录。
空白也照实显示——这是「内容尊严」在首页的具体做法，不是装饰。

数据全部来自 `source/_posts` 与 `source/_data/{projects,games,collections}.yml`，
共 16 条，构建期现算，不手写。

三个层次的分工：图纸给「到达感」，仪表给「可操作」，档案给「可读」。三者不重复
表达同一件事——图纸上只有身份与年度位置，仪表上只有时间轴与当天读数，档案上是全部标题。

**类型靠字形区分**，不靠卡片：文章空心圆、项目菱形、游戏方块、收藏粗环（与
`/library/<slug>/` 年轴上的 `fs-glyph` 同一套形状语汇）。

## 4. 动态行为（四种不同性质）

| # | 性质 | 具体行为 | 触发 | 时长 / 曲线 |
|---|---|---|---|---|
| 1 | 入场编排（一次性） | 图纸自下而上「落纸」（`clip-path: inset(100% 0 0 0)` → `inset(0)`）；身份三行 80ms 交错上移；仪表刻度自左而右逐根生长（每根 22ms 递延）；月条自轴线下落；光标淡入 | 首次进入 | 图纸 700ms `cubic-bezier(.23,1,.32,1)`；刻度铺开约 1.1s |
| 2 | 滚动空间转换（持续） | 图纸 sticky 钉住 194px，仪表从下方升起覆盖图纸下缘；同时照片 `scale(1) → .94`、身份块 `translateY(-30px)`、不透明度 `1 → .6`；右下角年度读数在仪表压上来之前先退场（`p=0.2` 剩一半、`p=0.4` 归零），不被上沿横切 | 滚动 | scroll-linked（rAF 合帧，只写 `--mz-p`） |
| 3 | 刻度 scrub（**标志性交互**） | 拖动 / 点击 / 键盘移动光标，读数条即时换日换记录；当天在档案里的行亮起左标记；空日显示「这一天没有记录 · 本月 N 条」 | 指针拖拽 / 点击 / ←→ / PgUp·PgDn / Home·End / Esc | 光标位移 130ms `ease-out`（拖动时关闭过渡，保持跟手）；读数切换即时 |
| 4 | 行 ↔ 条联动（指针与焦点） | 悬停或聚焦某条档案，刻度上它所在月份的那根条转 accent 实心 | hover / focus-visible | 160ms |

难度参数沿用 `home-redesign-comps-2026-11-14.html` 里已定的口径：一次会话只发生一次的
入场可以慢（560–760ms），高频交互几乎察觉不到（140–200ms），只动 `transform` /
`opacity` / `clip-path`。

## 5. 标志性交互的逐步状态

对象：`<div class="mz-scale" role="slider" tabindex="0">`。

| 状态 | 视觉 | 键盘 |
|---|---|---|
| 默认 | 光标停在「今天」，读数条显示今天的记录（今天无记录 → 「今天还没有记录 · 本月 2 条」） | `Tab` 聚焦，焦点环 2px accent |
| 指针按下 | 光标线转 accent、尺体加 `.is-dragging`（`cursor: ew-resize`、禁文本选择） | — |
| 拖动中 | 光标跟手，读数按天实时切换；经过有记录的月份时该月条变实心 | — |
| 松开 | 落点距某个「有记录的日子」< 24px 时吸附过去（触摸端的主要命中方式） | — |
| 点击刻度 | 直接定位到该日 | — |
| 逐日 | — | `←` `→` 前后一天；`Shift` + 方向 = 7 天 |
| 跳记录 | — | `PageUp` / `PageDown` 上一条 / 下一条记录 |
| 复位 | — | `Home` 最早一条；`End` 今天；`Esc` 回今天 |
| 读数条 | `2026-11-04`｜`1 条记录 · 文章`｜标题链接（同日多条显示前 2 条 + 「另有 N 条」） | 读数条里的标题是真链接，可 `Tab` 进入 |
| 空日 | 日期照常，右侧「这一天没有记录」，无链接、不用错误色 | 屏幕阅读器从 `aria-valuetext` 得到「2026 年 10 月 20 日，没有记录」 |

`role="slider"` 的 `aria-valuemin/max/now` 用「距最早记录第几天」，`aria-valuetext`
给人类可读的日期与当天内容。

## 6. 桌面 / 移动 / 键盘 / 减少动效 对照

| 场景 | 桌面（≥1100px） | 移动（≤767.98px） |
|---|---|---|
| 图纸 | 66svh，sticky 钉住 26svh | 66svh，不钉住（`position: relative`，避免地址栏伸缩抖动） |
| 仪表 | 升起后留在档案区顶部，不钉住 | 同左，`padding` 收窄、年标签保留 |
| 刻度宽度 | 版心 1200px | 通栏减 34px，热区 `touch-action: pan-y`（竖滑交给浏览器，横拖归刻度） |
| 主要操作 | 拖动 / 悬停 | 点按刻度、松手吸附到最近的记录日；档案行本身就是入口 |
| 档案行 | 日期 / 类型 / 标题 / 元信息 / 箭头 六列 | 两行重排：日期与类型在上、标题在下，元信息隐藏 |
| 提示文案 | 「拖动刻度…← → 逐日 · PgUp/PgDn 跳记录」 | 「点按刻度查看某天的记录」 |

键盘顺序：导航 → 刻度尺 → 读数条链接 → 16 条档案 → 6 个门。所有交互都有 `:focus-visible`。

`prefers-reduced-motion: reduce`：
- 关闭入场编排（`animation: none`，直接呈最终态）；
- 关闭滚动转换（图纸 `position: relative`、舞台 `height: auto`、`--mz-p` 恒为 0）；
- 关闭位移类 hover（箭头只变色不动）；
- **保留**：scrub 的全部功能与即时读数、焦点环、行↔条联动、展开状态与操作结果。
  已实测：reduce 下 `PageUp` 仍能定位到 2026-11-04 并点亮对应档案行。

## 7. 技术选择与性能风险

- **零新依赖**。原生 CSS + 约 10 KB 原生 JS（`source/js/home-measure.js`），沿用站点既有
  的 `/js/*.js` + `tools/stamp-assets.mjs` 内容 hash 链路。
- 刻度、月条、年标签、档案行、去处全部**服务端渲染**（Astro 构建期算好，`--x` 百分比定位，
  与 `/library/<slug>/` 年轴同一套语言）。JS 只做光标位置与状态类，不生成内容；禁用 JS 时
  刻度、档案、链接全部可读可点。
- 滚动用 `passive` 监听 + `requestAnimationFrame` 合帧；只写一个 CSS 变量 `--mz-p`，
  由 CSS 消费，避免 JS 直接写样式引起重排。
- 图片沿用既有 `source/img/cities/hangzhou.jpg`（`fetchpriority=high`），不新增请求。
- 几何等式（一条，决定首屏与退场都不出缝）：**图纸高 = 舞台高 − 194px**，于是
  「钉住行程 = 仪表实测高度 = 194px」。静止时仪表上沿贴住照片下缘；钉住结束时仪表下沿
  正好压到照片下缘，档案区不会漏出一条照片。仪表若因换行变高，压进的部分只多不少。
  高度用 `calc(88svh - 194px)` 表达（减法安全；加法会被压缩器吃掉空格，E-064）。
- 风险与处置：
  - `100svh` 旧浏览器不识别 → 每条高度声明前一行给 `vh` 兜底；
  - 移动端地址栏伸缩导致 sticky 跳动 → 窄屏不钉图纸；
  - 悬停联动在触屏无效 → 同一份联动绑在 `focusin`，键盘同样触发。

## 8. 明确不做的事

- 不做横向滚动劫持、不做整页滚动进度条、不做鼠标跟随光斑；
- 不做跨页共享元素转场：本站是多页静态站点，要为归档、文章、城市等全部页面加
  `@view-transition` 与首屏内联样式，影响面超出本次范围；改为行内按下反馈 + 箭头位移，
  保证点击后有明确反馈、不延误导航、不阻止浏览器返回；
- 不改 `_data` 里任何数据、不改 URL、不改导航结构，不动未提交的 `games.yml` / `projects.yml`。

## 9. 与初稿的差异（实施中改的，都因为真实数据或真实界面）

| 初稿 | 落地 | 原因 |
|---|---|---|
| 刻度上一「天」一个齿点 | 单位改「月」，条高 = 当月条数 | 16 条记录里 5 条挤在 18px 内（2026-10-15/18/21/11-01/11-04），日齿点糊成一团且点不中（E-167） |
| 仪表 `position: sticky` + 压缩态 | 留在档案区顶部、不钉住 | 站点导航是悬浮胶囊、没有实心条，钉住的仪表会在导航下方切出半截标题；压缩态又要吃掉 180px 视口 |
| 光标带浮动日期牌 | 只留光标线 + 读数条 | 浮动牌会遮住刻度上缘，读数条已在同一屏内 40px 处 |
| 照片上叠渐变压暗（radial + linear） | 整幅均匀压暗 26% + 字身投影 | A14「新增 CSS 不放渐变」是既有硬约束，压暗的目的是可读性不是装饰 |
| 移动端保留小幅钉住 | 窄屏不钉 | 地址栏伸缩时 sticky 会跳，窄屏首屏高度更宝贵 |
| 读数（距元旦）整块留在原位 | 随滚动退场（`p=0.4` 归零） | 仪表上沿会横切它，退场比被切一半干净 |
| 入场动画挂在 `.mz-clock` 上 | 改挂 `.mz-clock > *` | `animation: both` 的填充值会压死滚动退场的 opacity（E-168） |
