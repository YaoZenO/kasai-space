# 前端设计缺陷审查 · 2026-11-01

**审查对象**：线上 V6.3（`https://www.040925.xyz`，commit `29bb6df`）
**审查方式**：真实页面截图（1440×1000 / 390×844，12 个路由）+ Playwright 计算样式度量
**配套排期**：`DESIGN-ROADMAP-2026-11-01.md`
**方向拍板**：主人 2026-11-01 选定 **C 暖纸 + 保留轻玻璃**（对比图 `design/design-directions-2026-11-01.png`）

---

## 一、结论摘要

V6「Ties 蓝玻璃」的**材质与结构是成立的**（玻璃胶囊、玻璃浮层、四色光场都真实在渲染），
但存在三个层面的问题：

1. **内容级缺陷会直接漏到读者眼前**——归档摘要把 `&#x2F;` 当普通文字显示（P1）。
2. **色温与站点气质相反**——冷蓝 ambient + 品牌蓝强调，压不住「纸面/长文/文化资料」的内容属性；
   同时玻璃的白高光在冷底上偏「UI 控件」，不像个人空间。
3. **局部仍然散**——模块列表页 H1 字重与全站不一致、图像卡叠字、归档页内容重复两遍。

本轮不改结构、不加新装饰，只做两件事：**把有证据的缺陷修掉**，**把色板/光场/玻璃迁到暖纸体系**。

## 二、缺陷清单（按证据建档）

等级口径：P0 数据/内容损害 · P1 静默错误或读者可见的破绽 · P2 视觉/体验缺陷 · P3 打磨项。

| 编号 | 等级 | 现象 | 证据 | 根因位置 |
|---|---|---|---|---|
| **D-01** | **P1** | 归档页「C++ 求职学习路线」摘录中直接显示 `&#x2F;`，读者看到的是机器串 | 线上 `/archives/` 桌面与移动截图；Playwright 文本扫描命中 | `themes/fluid/scripts/helpers/excerpt-text.js` 的 `ENTITY_RE` 只解码 7 个白名单实体，未覆盖数字实体（`&#x2F;` / `&#46;` …）。helper 解码失败后 `<%= %>` 又转义一次 `&`，最终字面输出 |
| **D-02** | P2 | 文章内 377 处 11px 中文标签（StyleKit 文章的风格标签） | Playwright：`post` 页 `tinyCount=377`，全部来自 `.sk-tag` 11px | 文章自带 `<style>` 写死 `font-size:11px`（`source/_posts/stylekit-design-styles.md`），不是站点样式；站点 CSS 无权也不应改写单篇正文的自定义样式 |
| **D-03** | P2 | 游戏/项目/收藏列表页 H1 字重 700，其它页 600 | Playwright：`games` H1 `font-weight:700`，其余页面 600 | `source/css/site.css:2099` `.page-head-plain .page-head-title { font-weight: 700 }`，与 V5「标题字重一律 600」冲突 |
| **D-04** | P2 | 游戏卡「Esports Manager 2026」封面自带的艺术字与本卡叠加的「体育模拟 · 在玩」撞在一起 | 线上 `/games/` 截图 | 内容选图问题：封面本身含大字排版；`games-tile-cap` 已用 `rgba(29,29,37,.72)` 遮罩，不是对比度缺陷 |
| **D-05** | P2 | 「文字」页同 3 篇文章出现两次：上方「精选摘录」+ 下方年份列表 | 线上 `/archives/` 截图 | 设计形态（`archive.ejs` 精选 + `archive-list.ejs` 全量），但缺「为什么重复」的视觉区分，读者会以为列表出错 |
| **D-06** | P2 | 分类页每行下面的分隔线视觉上比其它页重，像 2px 墨线 | 线上 `/categories/` 截图 | `.category-list .cat-group` 顶线是 2px `--rule-strong`（全墨）；行线是 1px `--line-color`。截图里近黑是 2px 顶线在 5 行末尾各重复一次的视觉累积，不是取值错误 |
| **D-07** | P2 | 390 视口下「2026 年一览」日历只露出约 2/3 宽，无滚动提示 | Playwright：`.cal-row` right=578 > 390；`.cal-grid-wrap{overflow-x:auto}` + `.cal-grid{min-width:560px}` | 横向滚动是**有意设计**，页面本身无横向溢出（`docW=390`）。缺的是「还能往右滑」的可发现性 |
| **D-08** | P2 | 首屏主卡摘要读起来像数据转储：「来源：…（开源项目）说明：…」，末尾截成「；—」 | 线上 `/` 截图 | 摘要取原文前 N 字，未按句子边界收敛；`excerptText` 只截断不修剪悬空标点 |
| **D-09** | P3 | 404 页左上 kicker「404」与标题距离过近，字号 12px 蓝色在暖白底上偏弱 | 线上 `/404.html` 截图 | `.page-head-kicker` 复用全站 kicker 规格；404 的 kicker 是纯数字，letter-spacing .22em 让三个字符散开 |
| **D-10** | P3 | 短页面（标签/关于）正文结束后是大段空渐变，页脚悬在半屏 | 线上 `/tags/`、`/about/` 全页截图 | 内容量决定的自然留白，非布局故障；本轮不动 |
| **D-11** | **P1（方向）** | 冷蓝 UI + 纸面长文内容气质相反；玻璃高光像控件不像个人空间 | 主人对比图选择 C | 色板层（`site.css` tokens + 主题 `color:` 段 + 134 处字面色值） |
| **D-12** | P2 | `--surface-ink / --on-ink` 被 `test/css-tokens.js` 按字面值锁死，换色板会直接 FAIL | `test/css-tokens.js:94-97` | 断言把「当前配色」写成了契约；迁移必须同批改断言，否则测试红 |

### 已排除的误判（避免 E-039 型假阳性）

- 年历溢出：页面 `scrollWidth == clientWidth == 390`，**不是**页面横向溢出，是滚动容器内部。
- 游戏卡白字对比度：`games-tile-cap` 有 72% 墨底遮罩，不是「压在图上裸字」。
- 分类页线：不是 2px 行线，是组顶线的累积视觉。
- 11px 小字：不是站点 CSS 违规（`test/css-tokens.js` 的 ≥12px 断言对 `site.css` 全部通过），全部来自单篇文章自带样式。

## 三、与 Anthropic 的差距（方向依据）

| 维度 | 现行 V6.3 | Anthropic 品牌参数 | 差距判断 |
|---|---|---|---|
| 底 | ambient 冷渐变 `#f6f7fb→#f1f3f8→#f4f2f7` + 四色冷/桃/薄荷光斑 | `#faf9f5` 象牙白（暖） | 色温相反，是「不像」的第一因 |
| 主墨 | `#1d1d25`（冷黑） | `#141413`（中性暖黑） | 差距小，但纸不是暖的，墨也显冷 |
| 次级 | `#4c4c58` | `#6b6862` 暖灰 / `#b0aea5` 装饰灰 | 冷灰在暖纸上会发蓝 |
| 强调 | `#0a7cff` 品牌蓝 | `#d97757` 陶土橙（文字对比不足，仅作图形） | 蓝=科技 UI，橙=人文编辑 |
| 柔和底 | `rgba(10,124,255,.12)` 淡蓝块 | `#e8e6dc` 暖浅灰块 | 蓝块在暖纸上像贴纸 |
| 圆角 | 16px 玻璃卡 | 4–8px 克制圆角 | 16px 偏消费 App |
| 材质 | 玻璃 + 高光描边 + 蓝调阴影 | 无玻璃、无阴影、靠留白与规则线 | 材质语言不同 |
| 排版 | Fraunces 600 标题 / Nunito Sans 正文 | Poppins 600 标题 / Lora 正文 | 保留 Fraunces（主人已拍板衬线轨），只换色温 |

**取舍结论（C 方案）**：Anthropic 的「暖纸 + 墨 + 陶土」搬过来；玻璃材质**保留但暖化**
（半透明白改半透明暖白、阴影从蓝调 `rgba(31,38,80)` 改暖 `rgba(90,70,50)`、高光保留）。
不采用 Anthropic 的 4–8px 圆角（会与 V6 的 16px 标尺和既有组件冲突，属于 P2 重构）；
不换字体轨（Fraunces 是主人 10-31 明确保留的一项）。

## 四、本轮不动的已知项

- 字体轨（Fraunces 600 + Nunito Sans + 系统中文栈）——主人 10-31 拍板保留。
- 圆角标尺（16/12/8）与玻璃结构——保留，只改色温与阴影。
- 暗色模式——未校准，仍不启用。
- 单篇文章自带样式（D-02）、内容选图（D-04）——属内容层，另行排期。
- 归档页「精选摘录 + 全量列表」结构（D-05）——属 IA 决策，不在本轮扩面。

## 五、验证口径

修复后必须同时满足：

1. `npm run build` 成功，且抽查产物非 0 字节（E-029）。
2. `npm test` 全绿（含 `test/css-tokens.js` 的字号、token、圆角断言）。
3. 桌面 1440 与移动 390 截图复核：无横向溢出、玻璃可见、无新出现的低对比文字。
4. 归档页 DOM 文本中不再出现 `&#x2F;` / `&amp;amp;` 字面串。
5. 本审查所有「结论」都能被截图或脚本复现；不能复现的写「未验证」。
